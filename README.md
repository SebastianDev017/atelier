# Contour

Contour is an editorial Shopify theme built on Online Store 2.0. It ships with three presets: Contour, Annex and Maison.

- Documentation and support: https://sebastiandev017.github.io/atelier/
- Development reference: [DEVELOPMENT.md](./DEVELOPMENT.md) covers the stores, branches, deploy flow, the validation gate and the architecture.

## Building and checking

This needs the latest [Shopify CLI](https://shopify.dev/docs/api/shopify-cli).

```sh
shopify theme check        # must report 0 offenses
shopify theme package      # builds Contour-<version>.zip
```
